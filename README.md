# 🎮 Tic Tac Toe

A responsive and interactive Tic Tac Toe web application built using HTML5, CSS3, and JavaScript. The project focuses on implementing game logic, user interaction, and a clean responsive interface for a smooth gameplay experience.

## 🌐 Live Demo

[Play Tic Tac Toe](https://sonukumar19-eng.github.io/Tic-Tac-Toe/)

## ✨ Features

- Interactive two-player gameplay
- Alternating X and O turns
- Automatic winner detection
- Draw detection
- Restart game functionality
- Responsive design
- Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5 – Structure and game layout
- CSS3 – Styling, responsiveness, and UI design
- JavaScript – Game logic and user interaction

## 🎯 How It Works

Players take turns selecting cells on the game board. JavaScript tracks each move and checks the winning combinations after every turn. The game automatically detects a winner or declares a draw when all cells are filled.

## 🚀 Run Locally

Clone the repository:

git clone https://github.com/sonukumar19-eng/Tic-Tac-Toe.git

Then open `index.html` in your browser.
